# お菓子を食べ続けないと死ぬゲーム（仮） — 制作設定資料（2026-11-10）

## 決定事項

**本人が決めたこと**
- 題材は **ゲーム案ノート（2026-10-21）のハロウィン案**。仮装した子どもになってハロウィンの夜の街を走り、落ちているお菓子を拾い集める。カボチャやお化けがじゃまをする。お菓子が切れるとお化けにイタズラされて終わり。面白さは「食べ続けないと死ぬ」という分かりやすいルール（2026-11-10、連打で食べる案と比べてこちらを選択）
- 操作は **自動で奥へ走り、指で左右に動く**（2026-11-10）
- クリアは **朝まで生き延びる**。後半ほどお化けが増えて苦しい（2026-11-10）
- 終わり方は **大げさなイタズラ**。かわいいバカゲー寄り（2026-11-10）

**Claude 案（異論がなければこのまま）**
- **2D（Canvas）。夜の通りを少し斜め上から見下ろし、画面の上へ向かって走る**（3. 参照）
- スマホ縦画面基準（PC・横持ちもレスポンシブ）、結果画面に控えめな X 共有ボタン
- **お菓子の数がそのまま命**。子どもは走りながら袋のお菓子を勝手に食べ続けるので、数は時間で減っていく。拾って補う（2. 参照）
- **お化けが子どもに「お菓子ちょうだい」とせがむ**（トリック・オア・トリートの逆）。触れるとお菓子を取られる
- じゃまは 3 種類：カボチャ（置いてある）・おばけ（ゆらゆら近づく）・魔女のほうき（予告して横切る。後半だけ）
- **玄関の明かりがついた家の前を通ると、お菓子をどっさりもらえる**（道の端なので危ない所にある）
- 時間は約 90 秒で 21 時 → 朝 6 時。夜が深まるほど、食べるペースが上がり、お化けが増える
- イタズラは **最後にお菓子を取った相手で変わる**（4 種類）
- 画面の言葉と見た目を **「ハロウィンの夜」** でそろえる（お菓子袋・時計・玄関の明かり・結果は戦利品の袋）。学習メモ 10/28「一つの見立てでそろえる」
- 操作説明・キー設定は入れない（メモリの本人指示）

## 0. 面白さの分析（分解・考察・再構築）

学習メモ「企画・ゲーム設計」（10/14）の方法で分析した。

**分解：「食べ続けないと死ぬ」とハロウィンの面白い部分**
1. **持っている物が勝手に減っていく**：じっとしていても失う。安全な所にいるだけでは負ける
2. **減る物を取りに行くと危ない**：お菓子はお化けのそばや道の端にある。取りに行くか、見送るか
3. **数が減るほど焦る**：残り 3 個、2 個…で手に汗をかく。拾えた 1 個がうれしい
4. **ハロウィンの「お菓子くれないとイタズラするぞ」**：本来は子どもが言う側。これをお化けに言わせると逆転になる
5. **夜が明ければ終わる**：お化けの時間が終わる、というはっきりしたゴール

**考察：ゲームにすると**
- 1 が「食べ続けないと死ぬ」そのもの。子どもが勝手にもぐもぐ食べ続け、袋の数字が減る。見ているだけで「早く拾わないと」となる
- 2 が判断の核。左右に動くだけの操作でも、**お菓子の並びとじゃまの位置で「どこを通るか」を毎秒選ぶ**ことになる。玄関のどっさりは道の端＝カボチャやおばけが寄りやすい所に置き、大きな得と危なさをセットにする
- 3 は数字と子どもの表情で見せる（減るほど汗・涙目、袋がしぼむ）。拾ったら必ず音と数字の跳ねで返す（10/25 ノーリアクションをなくす）
- 4 を敵の性格にする：お化けは攻撃してこない。せがんでお菓子を持っていくだけ。持っていない子にはイタズラする
- 5 で 90 秒ほどの短い 1 回にまとめ、前置きなしですぐ走る（10/13 早めに操作させる）

**アイデアノート（01_アイデア）から取り入れたこと**
- **振り切った表現**（10/20 多数派にならないと死ぬ）：負けたときは「ゲームオーバー」の文字ではなく、大げさなイタズラで終わる
- **逆転の発想**（10/16 寿司の気持ち・ブロックになる）：お菓子をせがむのが子どもではなくお化け
- **判断の時間がだんだん短くなる緊張感**（10/14 ちくわぶデスゲーム）：夜が深まるほど、食べるペースが上がり、お化けが増え、走る速さも少し上がる
- **途中まで普通なのに、最後に「そうはならんやろ」**（10/12 だし巻き）：朝になって生還すると、食べた数に合わせて子どもがまんまるに太っている（たくさん食べたほどまるい）
- **誰もがやった遊びは分かりやすい**（10/13）：ハロウィンのお菓子集めは見ただけで分かる。説明を置かない方針と合う

**使わなかったもの**
- 文字と組み合わせる（10/12）：この題材の面白さ（減るお菓子と危ない道）と関係しないため
- 描いた線で遊ぶ（10/13）：操作は左右だけと決まっているため
- 間違えたら即終わり（10/14）：お化けに触れても即終わりにはせず、お菓子を取られるだけにする。お菓子の数そのものが命なので、緊張は「数が減る」で出す

**既存作品との重なり**
- **ハイジャンプ・デリバリー**（夜の街を季節の主役が跳び回る 3D）：夜の街・季節もので雰囲気が近い。違い：あちらは 3D で高く跳んで届ける、こちらは 2D で自動で走りながら **減っていくお菓子を補い続ける**。季節の言葉と見た目は被らない（雪とプレゼント ↔ カボチャとお化け）
- **DINO ESCAPE**（火山から逃げる 3D の走り）：自動で前へ進み、よけながら走る形が近い。違い：あちらは PC・横長でよけるのが主役、こちらはスマホ縦で **拾うのが主役**（よけるだけでは朝まで持たない）
- **お菓子量り売り**：お菓子という題材が同じ。遊び（重さを当てる ↔ 走って集める）は別物
- 自動で走って左右によけるのはよくある形（ランナー）。この作品の特徴は「お菓子＝命が勝手に減る」と「お化けにせがまれる」の 2 点に置く

**再構築**
- 核は **勝手に減っていくお菓子を、危ない所へ取りに行きながら朝まで保つ** こと
- 周りに「ハロウィンの夜の街」を置き、せがむお化け・玄関の明かり・夜明けで反応とゴールを返す

## 1. ゲーム概要

- タイトル：お菓子を食べ続けないと死ぬゲーム（仮）。候補：「トリック・オア・もぐもぐ」「お菓子が切れたらイタズラ」「朝までもぐもぐ」（決めるのは本人、後でよい）
- ジャンル・視点：自動で走るランナー／夜の通りを斜め上から見下ろす 2D、縦スクロール
- コンセプト：**お菓子を食べ続けないと、お化けにイタズラされる**
- 目指す楽しさ：残り少ないお菓子に焦る緊張／危ない所のお菓子を取れたうれしさ／玄関のどっさりの気持ちよさ／負けても笑える大げさなイタズラ／朝が来たときのほっとする感じ
- 基本の体験：タップ → すぐ走り出す → もぐもぐ食べながらお菓子を拾う → おばけにせがまれて取られる → 玄関でどっさり → 夜が深まって焦る → 朝になって生還（まんまる）／お菓子が切れてイタズラ → すぐもう一回

## 2. ゲーム内容

**プレイヤーの役割**：仮装した子ども（じゃまのおばけ・魔女と見分けやすい仮装。例：黒猫のねこ耳としっぽ）。お菓子袋を持っている

**基本操作**
- 子どもは画面の下 1/4 あたりにいて、自動で上へ走る（実際は背景が下へ流れる）
- **画面のどこでも指を置いて左右に動かすと、指の動いた分だけ子どもが左右に動く**（指で子どもが隠れないように、指の位置に合わせるのではなく動いた量で動かす）
- PC はマウスのドラッグ、または ← → / A D
- 道幅いっぱいに動ける。両端は家の前（玄関）

**お菓子（命）**
- 袋のお菓子の数＝命。最初は 10 個ほど
- 子どもは走りながら勝手に 1 個ずつ食べる。最初は約 1 秒に 1 個、夜が深まると約 0.6 秒に 1 個（食べるたびに口が動き、袋の数字が 1 減る）
- 道に落ちているお菓子に触れると +1。飴・チョコ・クッキーなど見た目は数種類あるが、価値は同じ（見分けで迷わせない）
- お菓子は線やカーブの形で並ぶ。続けて拾うと音が上がっていく（気持ちよさ）
- **玄関の明かりがついた家**：道の端に時々ある。前を通ると住人が「どうぞ」とどっさり（+8 ほど）くれる。端なのでじゃまが寄りやすい
- 数値は遊びながら調整（`CFG`）

**じゃま（Claude 案）**

| 種類 | 出てくる時間 | 動き | 触れたら |
|---|---|---|---|
| カボチャ | 最初から | 道に置いてある（動かない） | つまずいてお菓子を 3 個落とす。少しの間よろける |
| おばけ | 最初から（後半ほど多い） | ゆらゆら左右に揺れながら、子どもの方へ少し寄ってくる | 「お菓子ちょうだい」と 3 個持っていく |
| 魔女のほうき | 夜中（2 時ごろ）から | 横から一直線に横切る。来る 1 秒ほど前に、通る列に影と光で予告 | 5 個さらっていく |

- 触れた直後は少しの間（1 秒ほど）無敵で点滅（続けて取られすぎないように）
- お菓子が足りないときに取られたら、その時点で 0 になる

**夜の進み（約 90 秒）**
- 上に時計（21:00 → 6:00）。月が沈み、空が少しずつ明るくなる
- 夜が深まるほど：食べるペースが上がる／おばけが増える／走る速さが少し上がる／魔女が出始める
- 4 時を過ぎると空が白み始め、5 時半ごろからお化けが減っていく（最後は逃げ切りの気分）

**終わり方**
- **生還**：6 時に朝日が差して、お化けが一斉に逃げていく。子どもが立ち止まると、食べた数に合わせてまんまるに太っている（「そうはならんやろ」の落ち）→ 結果
- **イタズラ**：お菓子が 0 になった瞬間、周りのお化けがわっと集まって大げさなイタズラ（2 秒ほど）→ 結果。イタズラは最後にお菓子を取った相手で変わる

| 最後に取ったもの | イタズラ |
|---|---|
| おばけ | シーツをかぶせられて、おばけの仲間にされる |
| カボチャ（つまずき） | 頭にカボチャをかぶせられる |
| 魔女 | カエルにされる |
| 自分で食べきった | 寄ってきたお化けたちに顔じゅう落書きされる |

**結果（戦利品の袋）**
- 生還／イタズラ（イタズラの絵つき）
- 何時まで生き延びたか（生還なら 6:00）、食べた数、拾った数、残ったお菓子
- 自己ベスト（保存できないときはなしで動く）
- 「もう一回」は 1 タップ。控えめな X 共有ボタン（結果カードの画像）

## 3. 制作方針

- 使用環境・技術：ブラウザ（Canvas 2D・素の JavaScript）。外部ライブラリなし。1 枚の HTML に結合。**2D にした理由**：縦スクロールの走りはスマホ縦と相性がよい／お菓子・お化けをたくさん出しても軽い／ほうき立て・分身反復横とびと同じ構成で早く作れる
- 素材：絵は Canvas で描く（画像ファイルなし）。効果音は WebAudio で合成（拾う音・もぐもぐ・取られる・つまずく・どっさり・夜明け・イタズラ）。BGM は Phase 3 で入れるか判断（入れるならメモリの一回限りスクリプトの方法で 1 つだけ）
- 見た目の方向性：**かわいいハロウィンの夜**。紺と紫の夜空、オレンジの窓明かりとカボチャ。お化けは怖くなく、まるくてとぼけた顔。お菓子は明るい色で暗い道に映える。子どもは減るほど焦った顔になる
- 画面の配置（縦）：上に時計と空、真ん中が流れてくる道、下 1/4 に子ども。お菓子の数は子どもの近く（袋の上）に大きく出す（目線を動かさずに見えるように）
- 横持ち・PC：道の幅は縦と同じに保ち、左右に家並みを広げて見せる
- 優先順位：走る・拾う・減る・取られるの手応え → 夜の進みと玄関・魔女・終わり方 → 見た目・音・結果カード

## 4. 技術的な実現方法（Claude）

- **入力**：pointerdown/move/up で横の移動量を取り、子どもの x に足す（道幅で止める）。キーは押している間一定の速さで動かす。`touch-action: none`、`user-select: none`、コンテキストメニューを止める
- **流れ**：世界の y 座標を走った距離で進め、出てくる物（お菓子の並び・カボチャ・おばけ・玄関・魔女）は「区画」単位で前もって並べる。区画の型（お菓子の線、カボチャの間を抜ける、玄関とおばけ…）を夜の時間で重みを変えて選ぶ
- **公平さ**：区画を作るとき、カボチャで道がふさがらない（必ず通れる幅がある）ことを確かめる。魔女は予告してから横切る
- **お菓子の減り**：食べる間隔を時刻で補間（`CFG`）。数・食べた数・拾った数・最後に取った相手を状態に持つ
- **当たり判定**：円どうしの距離（子ども・お菓子・お化けは円、カボチャも円）
- **乱数**：シード付き（検証で同じ夜を再現できるように）
- **共有**：スマホ＝Web Share API（結果カードの画像付き）、PC＝X の投稿画面（文章＋URL）
- **構成**：これまでと同じく `src/` を分けて `sh build.sh` で `okashi-halloween.html`・`index.html`・`verify.html` に結合。ロジックは画面なしの `src/20-logic.js`、調整用の数値は `src/10-config.js` の `CFG`
- **検証（verify.html、ボットで夜を走らせる）**：
  - **よけるだけのボット**（お菓子を取りに行かず、じゃまだけよける）は朝まで持たない（＝拾いに行く必要がある）
  - **拾うだけのボット**（じゃまを気にせず一番近いお菓子へ）も朝まで持たないか、ぎりぎり（＝よける意味がある）
  - **拾いつつよけるボット**は朝まで届く（＝クリアできる）
  - 区画が通れない形を作らない（全区画で通れる幅がある）
  - 0 になったら終わる／最後に取った相手でイタズラが決まる／90 秒で夜が明ける

## 5. 仕様上の問題と対応案（Claude・実装前の報告）

1. **左右に動くだけで単調になる**：→ 「勝手に減る」で安全策を取れなくし、お菓子を危ない所（お化けのそば・玄関＝道の端）に置いて毎秒の選択にする。ボットで「よけるだけ」「拾うだけ」が両方負けることを確かめる
2. **指で子どもが隠れる**：→ 指の位置ではなく、指を動かした量で子どもを動かす。子どもは下 1/4 に置き、指は画面のどこに置いてもよい
3. **お菓子の数を見ていられない**：走りながら上の数字は見られない → 数を子どもの袋の上に出し、減るほど袋がしぼむ・子どもが焦る。残り 3 個以下で袋が揺れて音で知らせる
4. **理不尽に取られる**：上から急に来たり、横から見えずに当たる → お化けは画面の上から余裕をもって出す。魔女は 1 秒前に予告。触れた直後は 1 秒ほど無敵（ハイジャンプ・デリバリーで本人が「ぎりぎりすぎる」を嫌ったので、よけられる余裕は広めにとる）
5. **運で詰む**：お菓子が来ない区画が続いて 0 になる → 区画の選び方で「お菓子のない時間」が続きすぎないようにする（減るペースに対して拾える量の下限を決める）
6. **90 秒が長い・短い**：→ 時間と夜の進みは `CFG`。本人のテストプレイで決める
7. **負けがつらい**：→ 負けは大げさなイタズラで笑えるようにし、1 タップですぐ再挑戦。何時まで生きたかを出して「次は朝まで」と思えるようにする
8. **ハロウィンが過ぎている**：今は 11 月。季節外れでも遊べるように、ハロウィンの日付には触れず「ハロウィンの夜」の見た目だけにする。公開の時期は本人の判断
